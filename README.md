# 🏺 Археологтың құпия қазбасы · «Тастан қолаға дейін»

Ежелгі Қазақстан аумағындағы **тас дәуірі** мен **қола дәуіріне** арналған толық жұмыс істейтін
интерактивті тарихи ойын-сайт. Тіркелусіз, аты-жөнін сұрамай, бірден ойнала бастайды.

Барлық ойын логикасы браузерде жұмыс істейді: **HTML5 + CSS3 + Vanilla JavaScript**.
React, Vue, backend немесе database қолданылмаған.

---

## 🚀 Жариялау (GitHub Pages)

1. Осы репозиторийдегі файлдар: `index.html`, `style.css`, `script.js`, `sw.js`.
2. GitHub → **Settings** → **Pages** → *Build and deployment* → Source: **Deploy from a branch**.
3. Branch: **main**, folder: **/ (root)** → **Save**.
4. 1–2 минуттан кейін сайт мекенжайы дайын болады:
   `https://<пайдаланушы-аты>.github.io/<репозиторий>/`

> Барлық жолдар салыстырмалы (relative), сондықтан сайт кез келген ішкі қалтада да жұмыс істейді.

## ▲ Vercel

- **Add New → Project → Import** осы репозиторийді таңдаңыз.
- Framework Preset: **Other**, Build Command: **бос**, Output Directory: **бос** (немесе `.`).
- **Deploy** — дайын.

## 💻 Локальды тексеру

```bash
python3 -m http.server 8080
# немесе
npx serve .
```
Содан кейін `http://localhost:8080` ашыңыз.

## 🎮 Ойын құрылымы

| Деңгей | Атауы | Механика | Ұпай |
|---|---|---|---|
| LEVEL 1 | 🔎 Қазба алаңы | Топырақ қабаттарын қазу, 10 жасырын артефакт (click + touch, dust animation, геосканер) | 10 × 5 = 50 |
| LEVEL 2 | 🏺 Артефакт сараптамасы | 12 тапсырма, дұрыс +5, қате −2, «💡 Археологтың кеңесі» | 12 × 5 = 60 |
| LEVEL 3 | ⏳ Уақыт машинасы | Drag & Drop (pointer events — mouse + touch) немесе «таңда → бас», әр карточкаға ⏱ 20 сек | 10 × 5 = 50 |
| LEVEL 4 | 🕵️ Тарихи детектив | ДӘЛЕЛ → ТАЛДАУ → ҚОРЫТЫНДЫ, 8 із кесу тапсырмасы | 8 × 5 = 40 |
| LEVEL 5 | 🏆 Қорытынды сынақ | 10 аралас тапсырма: тест, артефакт анықтау, хронология, сәйкестендіру, сұрыптау (drag&drop), логика, дәлел, дәуір, технология, қорытынды | 10 × 10 = 100 |

**Жиынтық:** 300 шикі ұпай → финалда 100 балдық жүйеге нормаланған нәтиже (`пайыз = жиналған / максимум × 100`).

### Ұпай және мүмкіндік жүйесі
- Дұрыс жауап: **+5** (Level 1–4) немесе **+10** (Level 5)
- Қате жауап: **−2** (ұпай 0-ден төмен түспейді)
- ❤️ 3 мүмкіндік: Level 4 пен Level 5-те екінші қате жауапта, таймер біткенде немесе
  көпқадамды тапсырма 3 рет қате орындалғанда жоғалады.
- Мүмкіндік 0 болса → **«ЭКСПЕДИЦИЯ АЯҚТАЛДЫ»** экраны: `[ҚАЙТА ОЙНАУ]` `[БАС МӘЗІР]`.

## 🧩 Мүмкіндіктер

- **Басты экран:** тек атау, сипаттама және `▶ ОЙЫНДЫ БАСТАУ` — профиль/тіркелу жоқ.
- **HUD:** ⭐ ҰПАЙ · 🏺 АРТЕФАКТ 0/10 · ❤️ МҮМКІНДІК · ЭКСПЕДИЦИЯ ПРОГРЕСІ (progress bar).
- **Навигация:** 🏠 Басты бет · 🗺️ Экспедиция · 🏺 Артефактілер · ⏳ Уақыт картасы
  (құлыпталған деңгейлер 🔒 белгісімен).
- **Артефактілер мұражайы:** табылмағандары 🔒, карточканы басқанда толық modal
  (атауы, материалы, қолданылуы, дәуірі, тарихи маңызы).
- **Уақыт картасы:** Палеолит → Мезолит → Неолит → Энеолит → Қола дәуірі (қысқа фактылар).
- **Финал:** 🏆 confetti, ұпайдың count-up анимациясы, артефакт саны, рейтинг.
- **📜 Сертификат:** автоматты жасалады, браузердің *Басып шығару → PDF ретінде сақтау* арқылы сақталады.
- **localStorage:** прогресс, ұпай, ашылған деңгей, артефакттар, қателер сақталады;
  бет жаңарғанда **«ОЙЫНДЫ ЖАЛҒАСТЫРУ»** шығады. «ЖАҢА ОЙЫН» барлығын тазалайды.
- **Офлайн:** `sw.js` (service worker) ойын файлын кэштейді; шрифт жүктелмесе — fallback жұмыс істейді.
- **Дыбыс:** WebAudio арқылы жасалған (сыртқы файл жоқ), 🔊/🔇 батырмасымен өшіріледі.
- **Анимация:** fade, slide, scale, card flip, artifact reveal, dust, progress, score, level unlock, confetti.
- **Accessibility:** жоғары контраст, `aria-label`, `role`, keyboard navigation (Tab + Enter/Space),
  focus states, `aria-live` toast, `prefers-reduced-motion` қолдауы, 320px-тен бастап responsive.

## 📚 Тарихи негіз

Мазмұн Қазақстан аумағындағы тас және қола дәуірінің археологиялық деректеріне негізделген:

- **Палеолит** — Қаратау жотасындағы тұрақтар (Арыстанды, Тұрғысбай, Шақпақата, Обалысай),
  қолшапқы, шапқыш, қырғыш, аңшылық пен терімшілік.
- **Мезолит** — микролиттер, садақ пен жебе.
- **Неолит** — керамика, тасты тесу/жылтырату/бұрғылау, егіншілік пен мал шаруашылығының басталуы.
- **Энеолит** — мыс-тас дәуірі, Солтүстік Қазақстандағы **Ботай** мәдениеті (жылқыны қолға үйрету).
- **Қола дәуірі** — андронов мәдениеті, Орталық Қазақстандағы **Беғазы-Дәндібай** мәдениеті,
  қола қанжар/білезік, жерлеу ғұрпы, **Тамғалы** петроглифтері (ЮНЕСКО, 2004 ж.).

Күмәнді деректер нақты факт ретінде берілмеген; хронология мектеп оқулығындағы
қабылданған кезеңдеуге сәйкес келтірілген.
